# Política de segurança

Comunique vulnerabilidades do Argosvig CRM de forma privada aos responsáveis pelo projeto por meio do GitHub. Inclua a versão afetada, os passos para reproduzir e o impacto observado. Remova credenciais, documentos e dados pessoais dos exemplos antes de enviar.

Consulte o [histórico de correções](CHANGELOG.md) para identificar as versões afetadas e as correções disponíveis.
